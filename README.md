# FFXIV Plugin and Opener Sheet

Static site, no build step for hosting: `index.html` is the page, and GitHub Pages serves it.

`ffxiv-plugins-and-openers.md` and `ffxiv-plugin-catalogue.md` hold the research. `build_site.py` and `site_template.html` regenerate the page, and need the local `dl/` downloads, which are not committed.

To update: edit, commit and push. GitHub Pages redeploys in about a minute.
